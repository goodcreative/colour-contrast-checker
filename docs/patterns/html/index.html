Hexagonal Architecture (Ports & Adapters)

hexagonal-architecture.html
adaptersdependency-injectiontestability

The store reaches the URL and localStorage through injected port interfaces, so it can be tested with in-memory fakes and retargeted to new storage without touching logic.

Two-Stage Computed Pipeline

two-stage-computed-pipeline.html
reactivitycomputedperformance

Splitting scoring from bucketing into two chained computed properties means an AA/AAA toggle never re-runs colour maths — only the cheap second stage invalidates.

URL Codec

url-codec.html

One module encodes palette state to query params and decodes/validates them back into a complete typed shape — unrecognised values fall back to defaults before they ever reach the store.

Incremental TypeScript Migration

incremental-typescript-migration.html

The engine is being ported to TypeScript one file at a time; allowJs plus a Vite resolveId shim mean .js imports keep resolving after a module becomes .ts, so no big-bang rewrite and the existing tests stay untouched.
